# CAOS

Лабораторная работа по дисциплине "Архитектура компьютера и операционные системы".

Если диск, на котором лежит папка с логами, заполнен больше чем на X %, скрипт архивирует
N самых старых файлов (по дате изменения) в `backup` и удаляет их из папки с логами.
N выбирается минимальным, чтобы заполнение стало не больше X %.

## Linux (Ubuntu)

`./linux/archive_logs.sh <папка_с_логами> [порог_%=70] [папка_для_архивов=<родитель>/backup]`
`LAB1_MAX_COMPRESSION=1 ./linux/archive_logs.sh /log   `

- Коды выхода: `0` всё хорошо, `1` ошибка, `2` порог недостижим (заархивировано всё, но диск всё ещё заполнен).


./linux/test_archive_logs.sh


Тесты создают виртуальный диск на 1 ГБ и прогоняют 5 сценариев, в каждом папка с логами весит больше 0.5 ГБ.
Диск — это tmpfs (диск в оперативной памяти), он подключается через `sudo mount`, поэтому тест спросит пароль.
После тестов всё удаляется.

## Windows


windows\archive_logs.bat <папка_с_логами> [порог_%=70] [папка_для_архивов]
set LAB1_MAX_COMPRESSION=1 & windows\archive_logs.bat D:\log


`windows\test_archive_logs.bat` — те же 5 тестов. Нужно запускать от имени администратора: виртуальный диск
(VHD) создаётся через `diskpart`. Используется встроенный `tar.exe` (Windows 10 1803+).
